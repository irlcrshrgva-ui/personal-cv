## About the Project

A responsive personal Curriculum Vitae webpage containing my profile, education, skills and interests, and contact information. Built with plain HTML and CSS.

## Files

- `index.html` — CV content and semantic page structure.
- `style.css` — colors, typography, layout, and mobile styling.

## View the Webpage

Download the project and open `index.html` in a web browser. No installation or build command is needed.

## Understanding the Code

- `<main>` wraps the CV. `<aside>` contains the personal and contact details.
- `<section>` groups the profile, education, and skills. Headings explain each group.
- `<link rel="stylesheet">` loads the design from `style.css`.
- CSS Grid creates the two-column layout. The `@media` rule stacks the columns on smaller screens.
- CSS variables in `:root` hold the shared colors.
- `mailto:` opens an email application; the GitHub link opens my profile.
